# Apps

Chrome extension apps live here.

## Current Apps

- [ad-filter](ad-filter) - ad-blocking and ad-review prototype with local logs and optional user-provided AI triage.
- [chrome-home](chrome-home) - calm new-tab dashboard with search, tasks, shortcuts, weather, and daily inspiration.
- [image-gallery-downloader](image-gallery-downloader) - gallery-first image downloader side panel.
- [codepen-library-saver](codepen-library-saver) - save CodePens as local HTML files with library sorting, tags, and fallback source capture.
- [session-keeper](session-keeper) - Session Buddy-style tab session dashboard with TXT export and code-block copy.
